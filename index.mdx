Pyren is an open-source Linux desktop application that replicates the HP OMEN Gaming Hub experience. It combines a privileged Rust daemon with an unprivileged Tauri + SvelteKit GUI, giving you full hardware control over your HP OMEN or Victus laptop without needing Windows. The daemon runs as a systemd service and communicates with the app over a Unix domain socket, keeping privilege boundaries clean and auditable.

## How It Works

Pyren is split into three programs that work together:

<Steps>
  <Step title="pyren-daemon (root)">
    A privileged Rust systemd service that owns the hardware — fan PWM, RGB, power profiles, GPU offsets. It listens on a Unix socket at `/run/pyren/daemon.sock`.
  </Step>
  <Step title="pyren (the app)">
    An unprivileged Tauri desktop app (SvelteKit frontend) that talks to the daemon over the socket. It never runs as root.
  </Step>
  <Step title="pyren-osd (widget)">
    A GTK layer-shell overlay for quick mode switching, triggered by a configurable hotkey.
  </Step>
</Steps>

Two CLI tools round out the installation: **`pyren-ctl`** for scripting daemon control, and **`pyren-check`** for standalone hardware compatibility checking.

<Note>
  Pyren requires a Linux kernel with the `hp-wmi` driver. The installer can optionally build and install a patched version of the driver that unlocks additional fan-speed capabilities not available in the stock kernel module.
</Note>
